Form validation - Old form example

  • Documentation
  • Questions or comments?

This test page demonstrates WET's form validation plugin automatically adding aria-hidden="true" attributes to the "required" text in the labels of mandatory fields.

Example

View code 
<div class="wb-frmvld">
		<form action="#" method="get" id="validation-example0">
			<div class="form-group">
				<label for="test" class="required"><span class="field-name">Select field</span> <strong class="required">(required)</strong></label>
				<select class="form-control" id="test" name="test" required>
					<option label="Select an option"></option>
					<option value="option1">Option 1</option>
					<option value="option2">Option 2</option>
					<option value="option3">Option 3</option>
				</select>
			</div>
			<div class="form-group">
				<div class="checkbox required">
					<label><input id="test2" name="test2" type="checkbox" required>Checkbox field <strong class="required">(required)</strong></label>
				</div>
			</div>
			<div class="form-group">
				<label id="test3label" class="required"><span class="field-name">Text field</span> <strong class="required">(required)</strong></label>
				<input class="form-control" id="test3" name="test3" aria-labelledby="test3label" required />
			</div>
			<button class="btn btn-primary">Submit</button>
		</form>
	</div>
